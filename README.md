# 🧩 Tech Stack Icons for MERN Developers

A curated collection of icons for commonly used **technologies and tools in the MERN stack**, designed to make your portfolio and project documentation more visually appealing.

## 🚀 What Can You Use It For?

### 💼 Build Your Portfolio

Showcase the technologies and tools you know by adding their icons to your **portfolio website**, skills section, or resume.

### 🛠️ Showcase Your Projects

Clearly communicate the **tech stack used in your projects** by adding the relevant technology icons to your project cards, README files, or documentation.

Whether you're building a portfolio or documenting your latest project, this collection provides a simple way to represent your technical skills visually.

## 📦 What's Included?

The repository contains icons for commonly used technologies across areas such as:

* **Frontend:** HTML, CSS, JavaScript, React, Tailwind CSS, Bootstrap
* **Backend:** Node.js, Express
* **Database:** MongoDB
* **Languages:** JavaScript, TypeScript, Java, C
* **Tools:** Git


## 🎯 Why This Repository?

Instead of searching for individual technology logos every time you build a project or update your portfolio, you can find commonly used tech-stack icons in one place.

**Build. Showcase. Document. Repeat.**
